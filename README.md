# 静水拾光 (JingShuiShiGuang)

> 静水流深，只为值得驻留；拾光成卷，且待岁月生花。

一款极简高级的白名单专注与自律浏览器扩展。支持 B 站网课防沉迷、番茄钟循环、专注数据日历与 3D 数据看板。

## ✨ 核心功能
- 🍅 **沉浸式专注**：自定义专注、休息时长，支持正计时与倒计时。
- 🛡️ **B站/网站白名单**：专注期间仅放行指定 UP 主、合集课程与网站，彻底杜绝摸鱼。
- 📊 **数据大屏**：纯原生代码手搓的 3D 数据看板，包含热力图、折线图与专注海报生成。
- 📅 **记录与待办**：每日/每周待办，本地数据日历，随时回顾专注成果。

## 🚀 安装方式
1. 下载本项目源码（或 Release 中的 `.zip` 包）。
2. 打开 Edge/Chrome 浏览器，进入 `edge://extensions/`。
3. 开启“开发人员模式”，点击“加载解压缩的扩展”，选择本文件夹即可。
